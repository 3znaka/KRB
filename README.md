# KOROBOK (KRB) Map Engine

<img src="https://3znaka.github.io/KRB/js/img/logo.svg" alt="KOROBOK Logo" width="250">

KRB is a mapping library designed for rendering interactive 2D and 3D maps. It provides a comprehensive set of tools for terrain visualization, vector data rendering, and spatial data management, suitable for complex geographic information systems and custom mapping solutions.

## Integration

To include KRB in your project, use CDN:
```html
<link href="https://cdn.jsdelivr.net/gh/3znaka/KRB/KRB.css" rel="stylesheet">
<script type="module">
  import * as KRB from 'https://cdn.jsdelivr.net/gh/3znaka/KRB/js/KRB.min.js';
</script>
```

Or use the provided CDN mirror. This ensures reliable access even if primary repository hosting is temporarily unavailable:
```html
<link href="https://cdn.mapengine.ru/min/KRB.css" rel="stylesheet">
<script type="module">
  import * as KRB from 'https://cdn.mapengine.ru/min/js/KRB.js';
</script>
```
